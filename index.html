为什么学起来这么简单

三个核心设计，让零基础也能一天上手

音

一音一标

16 个字母，辅音 11 个、元音 5 个。没有清浊对立，没有送气区别。学完字母表就能拼读所有词。

词

词汇系统化

按名词、动词、修饰语、语法词分类。n 形式让每个词都能衍生出对应的新词，词与词之间形成网络。

法

粒子词框定

用 a / e / an / en / o / on 等粒子词标记句子成分。语序清晰，主-谓-宾一眼可辨。

书

两套文字

拉丁写法 walin 与象形写法 welin。象形字有七种字形来源，每个字都是一个故事。

思

无必要不区分

只要不造成歧义，就不用过分区分词性、词义。词是“软”的，随上下文流动。

外

外来语四步

思考 → 找音 → 拟音 → 合理化。外来语不是随便借用，能不用就不用，保持语音的独立性。

看一眼就懂

三个例子，说明配分语的核心特征

一、音节结构极简

每个音节只有四种可能：CV / V / CVn / Vn

⌒pa辅音 + 元音
|a单独元音
⫽̲san辅音 + 元音 + 鼻音
‖̲an元音 + 鼻音

二、粒子词划成分

a 标记谓语，e 标记宾语，an / en 标记“是”句型

finfin动物
aa谓语开始
<pu来
→ fin a pu. = 动物来了。

三、n 形式衍生词义

每个无 n 结尾的词，都有一个对应的 n 词

⊃fo吃 / 嘴
⊃̲fon说 / 语言
→ 都是嘴巴的行为，属于「延申」

四、象形字有故事

每个象形字都有字形来源

◡pe像笑脸，意思是“好的”
◯fi像人头，意思是“人”
⊖ya像“日”，意思是“太阳”
