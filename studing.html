配分语是什么

在学之前，先搞懂它是什么、为什么、怎么用。

配分语（PEFON）是由二项式顺铂团队中的 LJG 于 2026 年 7 月 29 日至 31 日，三天时间设计出的极简人造语言。目的是用更少的词汇、更简单的学习难度、更自然的语法，构建世界最简单的语言——一次对极简主义的践行。

极简

16 个字母

辅音 11 个，元音 5 个，坚持一音一标。没有清浊对立，没有送气与否的区别。

词汇

词汇系统化

按名词、动词、修饰语、语法词分类。n 形式让每个词衍生出对应的新词。

语法

粒子词框定

用 a / e / an / en / o / on / u 等标记谓语、宾语、表语、祈使、被动。

书写

两套文字

拉丁写法 walin 与象形写法 welin，都由左往右书写。

思想

无必要不区分

只要不造成歧义，就不用过分区分词性、词义。词是“软”的。

目标

更少的词汇，更简单的难度

用最少的词构建世界最简单的语言。

拓展 配分语由四个部分组成，共用配分词表和底层逻辑：
偏分 penfon：配分交流语
综分 sonfon：配分书面语
切分 sefon：配分专业语
噻吩 safon：配分社区语
本教程主要讲偏分部分。

字母与读音

16 个基本字母，坚持一音一标。

配分语只有 16 个基本字母。下面是 4×4 字母表。

辅音

发音位置齿前齿齿后
爆发音ptk
摩擦音fsh
鼻腔音mnl
元辅音wyø（无辅音）
提示 n 是比较特殊的辅音，可以作一个音节的结束音。当 n 位于音节末尾时，会根据后一个音节自由切换读音，例如 santa 里的 n 就是汉语的后鼻音 -ng。
拓展 虽然 l 的标准发音为“齿后鼻音”，但社区中大家热衷把它读作边音（汉语与英语中的“L”）。爆发音、摩擦音的清浊不分，是配分语辅音系统的一大特点。

元音

字母aeiou
汉语拟音啊耶的韵母衣哦巫
提示 e 的读音并不是“额”，而是“页”ye 的韵母读音。

结音变读

结音即结束音，此音节部分只有一个 n，但可以根据后一个音节读什么自由切换读音。

写法通常读法
sansan
samsam
sassas
sanssans
sankasanka
思考 想一想：n 在这些音前为何会变读为不同的音？试着发音后总结规律，这个变读规则复杂吗？

音节与合法

每个音节必须遵循（辅音）+ 元音 +（鼻音）的规则。

故配分语一共有四种音节模式：

音节模式例说明
CVpa辅音 + 元音
Va单独元音
CVnpan辅音 + 元音 + 鼻音
Vnan元音 + 鼻音

注：C = 辅音，V = 元音，n = 鼻音（韵尾）。

但是不难发现，wu 与 u、yi 与 i 很难区分，故我们不把它们和它们的衍生音节看作合法音节。

4 大不合法音节

wuwunyiyin
无法与 u 区分无法与 un 区分无法与 i 区分无法与 in 区分
拓展 非法音节在非正式交流时被赋予了独特含义，如“配分语教科书”为 yi。配分语所有的词都是单音节的，因此对中文使用者很友好。
拓展 我们之后可能会学到单个 n 所成的特殊语气词（读作“嗯”的鼻音部分），它不属于音节，所以进而不属于词的范畴。配分语允许连读，但前提是清晰，连读速读不作规范。

象形字表

横向是辅音，纵向是元音，交叉格子是对应音节的象形写法。

提示 象形写法是音节文字，每个象形字表示一个音节（一般 1~2 个字母），故叫 welin（两个字母的文字）。

七种字形来源

来源一

事物的象形

如 pe，意思是“好的”，字形像笑脸。

来源二

事物部分的象形

如 fi，意思是“人”，字形像人头。

来源三

拉丁字母的变形

如 lo，和意思无关，从首字母 L 变形而来。

来源四

以语法作用为核心

如 a，语法作用为“主谓连接”，故一条竖线。

来源五

道本图的衍生

如 wo，既是 W 的变形，也是道本语 wile 的道本图。

来源六

汉字的衍生

如 ya，意思是“太阳”，像中文的“日”。

来源七

约定俗成的符号

如 na，形状是数学的“无限”符号，表示“所有”。

n 形式写法

提示 象形书写系统并未向 -n 词多做字形。n 形式一般为在无 n 结尾形式下面加短横或点。例如：
fo
意思是嘴巴 / 食物 / 吃
fon
和 fo 有词义联系：意为语言 / 演讲 / 说……（字形在 fo 下方加一横）

第一课 · 你我他

配分语最基本的句子结构：主 - 谓 - 宾。

粒子词 a 放在谓语前，e 放在宾语前。

fin a pu.
狼来了。（动物 + a + 来）
hi a fo e ni.
你吃这个。（你 + a + 吃 + e + 这）
提示 主语前面的粒子词 o（旧教程是 on）通常省略。此处没有指明动物的具体类别，恰恰说明动物的种类在这一句话不重要——老鼠来了 / 蜜蜂来了 / 大象来了都没有问题。这是配分语的思想之一。
思考 为什么 a 是一条竖线，e 是两条竖线？
（提示：配分语最主要的句子结构是主-谓-宾，所以 a 大多数情况下是句子的第一个分隔符。）

词汇记忆

fi人
fin动物，如狗/猫/鸟/虫子/兔子/乌龟等，一般不包括人
si他 / 她 / 它
hi你
mi我
ni这，这个
fo吃
no看见
pu到来
拓展 其实主语也有粒子词 o（旧教程是 on），但是在句子头部省略是最好的写法。

练习

把下面中文翻译成配分语：

  • 你来了。
  • 他看见你。
  • 这是人。

第二课 · 这是

学习配分语的“是”句型。

今天我们学习配分语的“是”句型，有另外两个粒子词 an 与 en。它们本身都有“是”的意思，但是语法作用不一样。

  • an 后面接表语（饰词 / 形容词）
  • en 后面接宾语（名词）
fin an fa.
动物很大。
ni en fi.
这是人。
拓展 en 的旧写法是 an e，比较啰嗦，所以后来合并了。an 和 en 的区分是很有必要的，后面的课程就会讲到。

词汇记忆

pe好的
pa坏的
an“是”的表语起头粒子词
en“是”的宾语起头粒子词
fa大的
fe小的

练习

给下列中文句子试着加入配分语的 a / e / an / en 粒子词：

  • 小鸟吃苹果。
  • 虫子起床了。
  • 我挺高的。
  • 这是什么意思？

翻译下面句子：

  • 你来了。
  • 他看见你。
  • 他是好人。

第三课 · 朋友！

学习饰词的另一种用法：作成分的修饰语。

名词饰语

饰词放在名词前面，构成“名词饰语”。不同于简单的叠加，配分语的这方面思维不太一样。

pe fi
朋友（好 + 人）
pa fi
敌人（坏 + 人）
fe fin
虫子（小 + 动物）
fa fi
成人（大 + 人）
提示 名词连同它前面的饰语一起作为一个主语或宾语成分。例如 pefin（好的动物）相当于一个概念：益虫。

动词饰语与饰词饰语

动词饰语就是我们常说的“副词”中的一种。修饰动词时有一些意思有“形变而神不变”的变化。

si a pefan e fafin.
他十分了解大的动物。
hi an henpe.
你很好。
思考 hen 这个“很”刚好和汉语的很像，在学习中挖掘“巧合”是可以让你事半功倍的。

名词-饰词词性转换

其实配分语的词除了纯语法词外没有特定词性，由它在句子的位置和所充当的成分决定。

ni这的，近的
mi我的
si它/他/她的
hi你的
fi与人有关的，人道的
fin与兽有关的，残酷的
拓展 配分语也可以光说“好人”而不提“朋友”，为 pe li fi。使用以后很重要的语法词 li 来打断一个词的整体画面感。

第四课 · 词性空间

讨论 AB 与 BA 的饰语-后词词组之间的差别。

这个问题的本质是配分语的词性转换。

词性空间

配分语的单个词是由不止一个意义组成的；也是由不止一个词性组成的。

提示 被修饰的词称为“后词”“被修饰词”或“中心词”等。词性空间是配分语生造的语法术语，在其他语言中实在少见。
词动词义名词义饰词义
fo吃嘴，语言味觉上的
fi工作人人造的
fa出现体积大的
fe减轻，减花小，新，年幼
fin打击兽残酷的
hen充，锻炼力气，电很，狠，快的

说回 AB 与 BA 型的语义差别，实际上是由于修饰语词与后词互换时，词性也会互换导致的一种意义改变。

fa fin
大的动物，如大象
fin fa
动物的“大”，即动物的大小 / 体积
fe fi
小孩 / 矮人
fife
人造的花，假花

词性填充思想

配分语词的各个词性看着很“残废”，想要表达一种词义很有可能位于其他的词性。

拓展 在后续的学习中，其实使用语法词 li/u/un 等是可以严格区分地表述的。
提示 我们目前上手的是偏分部分。其思想中很重要的一部分是“无必要不区分”。只要不造成不可忽视的歧义，就不用过分地区分一个词在不同情况/不同词性下的词义。

n 形式

每个无 n 结尾的词都有对应的 n 词，意思一定有简单自然的映射关系。

可以分为以下七类：

延申

fo → fon

同一东西的两面。fo 是“吃”，fon 是“说”——动作的介质仍然是嘴巴。

对立

fi → fin

两者正好相反。fi 是“人”，fin 是“动物”。

类推

ki → kin

由相似的联想推得。ki 是“气体”，kin 是“火”——火势向上蔓延，和气体同理。

深化

i → in

同一个方向，程度更深。i 是“转，变得”，in 是“但是，反转”。

先后

te → ten

先有前者，后有后者。te 是“下，压”，ten 是“压爆、反抗”。

中例

ko → kon

取常见例子的特点。ko 是“液体”，kon 是“混乱的”——液体中最常见的例子是“酒”。

抽象

ke → ken

从具体而抽象。ke 是“坑、容器”，ken 是“安全、舒适”——从“待在坑里”抽象而来。

拓展 如果不要求精细分类（很多情况下一个无 n 词与 n 词的词组可以用不止一种方式解释），可以简单分为四类：
相反：对立和一些延伸；
联想：延申，类推，中例；
沉下：深化，先后；
抽象。

外来语

思考 → 找音 → 拟音 → 合理化。

配分语的外来语，写法上通常在象形字用 [ ] 框起，在拉丁写法中用大写字母来与普通文本区分。

拓展 不止外来语，常见的“不按词义来”的名字/拟声词等也会同样区分。例如 MIMI 指猫，或者叫如“咪咪”的事物等。

思考

思考 外来语固然是语言的一部分，然而配分语极力减少它的表达，因为它可能会渐令配分语的语音独立性被稀释。

这个外来语真的重要吗？在聊天中使用它会变得更好吗？不使用它就不行吗？它会引发新的歧义吗？

原则是：
· 听话人或读者需能听懂，不易搞混
· 有一定要用外来语的理由或者思想在其中

找音

配分语使用外来语以“完全看读音”而非任何字形或含义出发。找外来语的原音时，就得考虑这个外来语原本该选哪个语言的。结合配分语的思想，有了以下几条推论：

  1. 如果一个词语或者一句话是最常用的招呼语等，则选择各个语言都可以，如加油（TAYO）、二人（KONITIWA）、hello（HELO）等。
  2. 如果一个词语带有一个国家/语言的特色，那么就选择这个特定的语言，如中国（SONKO）、樱花（SAKULA）、美洲（AMELIKA）等。
  3. 如果一个词可以由第二条规则解释部分，则不加词，如汉语 = 中国·语言 =（SONKOfon）。
  4. 如果一个词很普通，或者不止一个语言的这个词都经常被使用，那么就从世界目前主流语言或听话者可听懂的语言取，如原神（YENSON / KENSIN）。

拟音

配分语的拟音没有硬性标准，但有一些成体系的拟音方式与方案。如中文，目前有 At_Yeso 的宽式与 LJG 的严式拟音法。宽和严对应两种思路：前者追求音的相似，后者则想方设法在音节数的对应下减少重码率。如油条 [you tiao] 的音译就应为 YUTO。

合理化

只需要避免会导致混淆的读音或不合理的字母组合，如 YI / WU / YIN / WUN 音节和 NN / NM 字母组合就行了。

.句号，表示句子间的分割，有语法意义
!感叹号，表示强调和惊叹
?问号
:冒号，表示列举或从句连接
"ko"引号，兼做中文书名号

大小写规范
